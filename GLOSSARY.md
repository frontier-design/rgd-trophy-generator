# RGD Generator

A workspace for shaping trophies from text and composing the resulting artwork.

## Language

**Scene**:
A text-and-trophy artwork whose typography determines the trophy's profile.

**Repeat artboard**:
A bounded repeating composition of symmetric trophies separated by centered copies of one text. The text determines the trophy profiles.

**Text gap**:
The text-bearing space between neighboring trophies in a repeat artboard. In the current design, every gap displays the same centered text.
